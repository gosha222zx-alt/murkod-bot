# Муркод — кот-ассистент

Муркод принимает текстовые и голосовые сообщения, помогает изучать Python,
отвечает через Groq API и сохраняет историю диалога. Также в нём есть игра
«Угадай число», статистика игроков, учебный план и оценка карьерных направлений.

## Установка

```bash
cd D:\python_basic_project
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Создай файл `.env` на основе `.env.example` и укажи токены:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
GROQ_API_KEY=ключ_от_Groq
```

## Запуск

```bash
python main.py
```

## Виджет рабочего стола

Локальный виджет для задач и проектов запускается отдельной командой:

```bash
python desktop_widget.py
```

Он оценивает задачу по описанию, сохраняет найденные навыки в `projects.sqlite3`
и показывает прогресс. Укажи папку проекта, затем кнопка `VS Code` откроет её
командой `code`, зафиксирует начало работы и позволит отметить результат двойным
кликом. Кнопка `—` переводит окно в компактный режим, `×` сворачивает его,
а `Выйти` полностью закрывает приложение.

Дополнительные интеграции включаются через `.env`:

```env
GITHUB_TOKEN=токен_с_правом_чтения_репозиториев
TELEGRAM_CHAT_ID=твой_chat_id
JOB_FEEDS=https://пример-сайта/feed.xml
GROQ_MODEL=openai/gpt-oss-20b
```

AI-разбор использует `GROQ_API_KEY`, GitHub-кнопка открывает последний репозиторий
аккаунта, а кнопка `Отчёт` отправляет текущий прогресс в Telegram. Для недельной
отправки запусти `python weekly_report.py` через Планировщик заданий Windows.
Заявки читаются только из разрешённых RSS/Atom-лент и открываются для ручной
проверки: приложение не отправляет отклики и не принимает финансовые решения
автоматически.

## Запуск 24/7 на сервере

Для бесплатного постоянного запуска подойдёт VM Oracle Cloud Free Tier.
Сервисы с бесплатным тарифом могут приостанавливать фоновые процессы, поэтому
для этого polling-бота нужен сервер, который не засыпает.

На сервере установи Docker, скопируй проект и создай `.env`:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
GROQ_API_KEY=ключ_от_Groq
```

Запусти бота:

```bash
chmod +x deploy.sh
./deploy.sh
```

Для просмотра текущих логов используй:

```bash
docker compose logs -f murkod
```

Команда `restart: unless-stopped` автоматически поднимет бота после перезагрузки
серверной VM. SQLite и история сохраняются в Docker volume `murkod_data`.
Не публикуй `.env` и не вставляй токены в Dockerfile или README.

В Telegram отправь ассистенту `/start`. Команда `/help` показывает список команд,
а `/clear` очищает историю текущего
диалога. Голосовые сообщения расшифровываются через Groq Whisper. Пока бот
формирует ответ, он показывает статус «печатает...». Если Groq недоступен, бот
 сообщит об ошибке.

При `/start` бот также отправляет видео Муркода из файла `telegram_avatar.mp4`.

Игровые команды Telegram:

- `/guess` — начать новый раунд;
- отправь число от 1 до 100 — сделать попытку;
- `/reset` — сбросить текущий раунд.
- `/stats` — показать количество игр, побед, поражений и среднее число попыток.
- `/top` — показать рейтинг игроков по количеству побед и именам Telegram.
- `/today` — показать текущий шаг 30-дневного плана обучения.
- `/done` — отметить сегодняшний учебный шаг выполненным.
- `/progress` — показать выполненные дни и процент прогресса.
- `/career` — получить персональную оценку по учебному прогрессу и играм, а также направления для заработка.
- `/market` — получить идеи ниш и проектов для портфолио.

Состояние игр сохраняется в локальной базе `games.sqlite3`, поэтому после
перезапуска бота активные раунды восстанавливаются. Файл базы создаётся
автоматически рядом с `main.py`.

Имена пользователей сохраняются в таблице профилей автоматически. Старые
результаты без профиля отображаются как `Игрок <chat_id>`.

Ключи не добавляй в Git: файл `.env` уже указан в `.gitignore`.

## Игра «Угадай число»

Оконная версия игры запускается без дополнительных библиотек:

```bash
python guess.py
```

В игре четыре попытки. Чтобы собрать один `.exe` для друзей, установи PyInstaller
и выполни команду в папке проекта:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name GuessMatrix guess.py
```

Готовый файл появится в папке `dist/GuessMatrix.exe`.

## Ежедневное обучение Python

В файле `learning_plan.json` находится 30-дневный план по 3 часа в день.
Чтобы показывать текущий шаг при входе в Windows, открой PowerShell в папке
проекта и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_daily_learning.ps1
```

Проверить уведомление вручную можно командой:

```powershell
python daily_learning.py
```

План начинается с даты `start_date` в `learning_plan.json`. После завершения
30 дней измени эту дату, если хочешь начать следующий учебный цикл.
